## Role Contract v0

### PM

- Input: original Human request.
- Output: smallest executable objective and constraints for later roles.

### Designer

- Input: Human request and PM output.
- Output: minimal file-based workflow shape and handoff expectations.

### Reviewer

- Input: Human request, PM output, Designer output.
- Output: blockers, risks, and scope-drift review.

### Worker

- Input: Human request plus PM, Designer, Reviewer outputs.
- Output: concrete implementation plan or implementation summary.

### Debugger

- Input: all prior outputs, especially Worker output.
- Output: actionable debug report with bugs, verification gaps, fixes needed, and pass/fail status.

### Integrator-C

- Input: Human request and all prior outputs.
- Output: final integrated handoff and next Unit signal.
